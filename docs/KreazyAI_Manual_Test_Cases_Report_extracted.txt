rendering, payment attempts or third-party Meta calls were performed.

staging branch before running mutation tests.

Execution rules
• Run non-mutating smoke tests first; never attempt payment fulfillment, live Meta sends or production DB
writes during exploratory QA.
• Capture browser name/version, viewport, device, UTC timestamp, test user role, request status, sanitized
response, screenshot and correlation ID.
• A test PASS requires observed output matching its expected result, including DB-level verification for
mutations.
• Use staging for concurrency, tenant-crossing and malformed webhook tests. Mark blocked cases BLOCKED
with the exact missing dependency.
